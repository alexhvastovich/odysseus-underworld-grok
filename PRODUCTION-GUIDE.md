# Odysseus in the Underworld — Grok Imagine Production Package

**Runtime target:** 4:00 (240 seconds)  
**Shots:** 26 (mix of 6–12s; two 10s anchor shots)  
**Source:** *Odyssey* Book 11 — Odysseus's nekyia, focused on ritual descent and the Tiresias prophecy  
**Workflow:** Reference stills → individual animated clips → **Stitch** in Grok canvas

---

## Quick start (when your limit resets)

### Step 1 — Lock references (still images only)
Open `03-reference-pack.md`. Generate and approve every master still before animating anything.

### Step 2 — Generate shots in order
Open `04-shot-list.md`. For each shot:
1. Read `prompts/shot-NN.md`
2. Attach the listed reference images (≤7)
3. Paste prompt into Grok Imagine
4. Generate → review → next shot

### Step 3 — Stitch
Open `05-stitching-order.md`. Select clips in order → **Stitch** (or type "stitch these together").

## Rules you must not break

- **Never** one-shot the full four minutes
- **Never** flip eyelines mid-scene (see 180° notes in shot list)
- **Never** animate before reference masters are locked
- **Alternate** dialogue with reactions and atmospheric inserts
- **No** glowing fantasy ghosts — shades are dim, human, smoke-obscured
